# 知识库 - MCP

## MCP 基础知识

### 这是什么
MCP（Model Context Protocol，模型上下文协议）是一种用于连接大型语言模型和外部工具的协议，是构建Agent系统的重要标准。

### 为什么Agent开发需要它
MCP是构建Agent系统的重要标准，支持模型与外部工具的上下文连接，是实现工具调用的关键技术。

### 设计师可以如何理解
MCP就像"设计意图到工具调用"的桥梁。你可以通过MCP理解如何将设计想法转化为智能的工具调用，帮助你更高效地设计和评估Agent系统。
