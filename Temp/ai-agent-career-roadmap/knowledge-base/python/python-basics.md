## Python 基础知识

### 这是什么
Python是一种高级编程语言，以简洁和可读性著称，被广泛应用于Web开发、数据分析、人工智能等领域。

### 为什么Agent开发需要它
Python是AI Agent开发的主要语言，FastAPI、LangChain、LangGraph等框架都使用Python，是实现Agent的核心技术栈。

### 设计师可以如何理解
Python代码就像是"设计需求到实现"的桥梁。你可以通过Python理解如何将设计想法转化为可运行的系统，帮助你更高效地沟通和协作。
