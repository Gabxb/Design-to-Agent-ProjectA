# 知识库 - Git

## Git 基础知识

### 这是什么
Git是一个分布式版本控制系统，用于跟踪文件的变化并管理代码版本。

### 为什么Agent开发需要它
Git是Agent开发中代码版本管理和团队协作的核心工具，支持分支管理、合并和冲突解决，是构建和管理Agent项目的关键技术。

### 设计师可以如何理解
Git就像"设计迭代到版本"的桥梁。你可以通过Git理解如何将设计想法转化为可版本化的代码，帮助你更高效地管理和迭代Agent系统。

### 最小代码示例
```bash
git init
git add .
git commit -m "初始提交"
git branch feature-1
git checkout feature-1
```
