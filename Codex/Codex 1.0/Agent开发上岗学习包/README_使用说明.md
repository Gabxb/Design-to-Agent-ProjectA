# Agent 开发上岗学习包 - 使用说明

资料日期：2026-08-11

## 文件

- `Agent开发上岗实战教程.md`：主教程，45 章 + 16 周计划 + 两项目 + 工程代码 + 评测 + 求职。
- `Agent开发上岗实战教程_打印版.pdf`：A4 打印版，封面、目录、页码。
- `Agent开发上岗实战教程_含Prompt.md`：主教程 + 20 个 Prompt 附录。
- `Agent开发Prompt库.md`：独立 Prompt 库。
- `Agent开发学习记录表.xlsx`：共 10 个工作表（含 Dashboard）的长期记录表；内置公式、筛选、条件格式与进度图。每日记录预填示例起始日为 2026-08-17，可按实际开学日修改日期列。
- `examples/agent_starter/`：可运行 Agent 工程骨架，随 ZIP 提供；生成时本地测试结果为 `6 passed`。

## 推荐顺序

1. 先做第 6 章入学测试；若短板明显，执行前置补课。
2. 严格按 16 周计划做，每天必须有 commit/test/eval/Trace/复盘之一。
3. 第 5 周必须手写 Agent Loop；不要跳过直接学框架。
4. 第 13-15 周完成两个作品集。
5. 第 16 周按结业评分表验收，再开始集中投递与模拟面试。

## 版本管理

快速变化框架的基线写在教程“版本与迁移风险矩阵”。实际项目必须提交锁文件；升级后先运行单测、集成测试、离线 eval、安全测试，再决定是否合并。

## 关于“上岗能力”

本学习包所说的“达到上岗能力”，指具备完成真实 Agent 项目中常见开发任务的能力，包括实现、测试、评测、安全、权限、可观测、成本和部署；不构成就业结果承诺。
