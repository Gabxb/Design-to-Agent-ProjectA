# PostgreSQL 与数据建模

## 1. 这是什么

可靠保存结构化业务数据的关系数据库。

## 2. 为什么 Agent 开发需要它

它参与 Agent 的输入、状态、工具、数据、评测或部署链路，是把模型能力变成可维护产品的基础。

## 3. 设计师可以如何理解

像信息架构：表是内容类型，外键是内容关系，索引是快速入口。

## 4. 最小代码示例

```python
SELECT id, title FROM requirements WHERE status = 'open' ORDER BY created_at DESC;
```

## 5. 工作中的使用方式

保存用户、任务、文档元数据、工具调用和评测结果。

## 6. 教学简化方案

先用一个输入、一个处理步骤、一个输出和一个错误案例跑通，不追求通用抽象。

## 7. 生产环境方案

使用迁移、事务、索引、连接池、备份和权限。

## 8. 常见错误

- 只验证顺利案例。
- 把配置、密钥或本地路径写死。
- 没有记录版本、输入、输出与失败原因。

## 9. 排查方法

缩小为最小复现；核对输入类型和环境；读取最底层错误；检查日志中的请求 ID；再核对最新官方文档。
