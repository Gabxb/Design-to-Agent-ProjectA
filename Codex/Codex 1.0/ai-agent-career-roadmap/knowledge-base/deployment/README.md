# 部署与运维

## 1. 这是什么

把应用稳定发布到可访问环境，并持续监控和更新。

## 2. 为什么 Agent 开发需要它

它参与 Agent 的输入、状态、工具、数据、评测或部署链路，是把模型能力变成可维护产品的基础。

## 3. 设计师可以如何理解

像把设计系统真正接入产品，而不只是留在演示稿中。

## 4. 最小代码示例

```python
@app.get('/health')
def health() -> dict[str, str]:
    return {'status': 'ok'}
```

## 5. 工作中的使用方式

提供 Demo、团队测试和真实用户访问。

## 6. 教学简化方案

先用一个输入、一个处理步骤、一个输出和一个错误案例跑通，不追求通用抽象。

## 7. 生产环境方案

CI/CD、健康检查、回滚、日志、指标、备份和成本告警。

## 8. 常见错误

- 只验证顺利案例。
- 把配置、密钥或本地路径写死。
- 没有记录版本、输入、输出与失败原因。

## 9. 排查方法

缩小为最小复现；核对输入类型和环境；读取最底层错误；检查日志中的请求 ID；再核对最新官方文档。
