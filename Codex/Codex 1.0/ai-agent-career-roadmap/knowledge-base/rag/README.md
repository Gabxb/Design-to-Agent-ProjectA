# RAG

## 1. 这是什么

Retrieval-Augmented Generation（检索增强生成）先检索外部知识，再基于证据生成答案。

## 2. 为什么 Agent 开发需要它

它参与 Agent 的输入、状态、工具、数据、评测或部署链路，是把模型能力变成可维护产品的基础。

## 3. 设计师可以如何理解

像设计评审前先翻规范并标出出处，而不是只靠记忆回答。

## 4. 最小代码示例

```python
contexts = retriever.search(query, top_k=5)
answer = generate(query=query, contexts=contexts)
```

## 5. 工作中的使用方式

企业知识问答、政策检索、文档助手和研究资料分析。

## 6. 教学简化方案

先用一个输入、一个处理步骤、一个输出和一个错误案例跑通，不追求通用抽象。

## 7. 生产环境方案

评测解析、检索、引用、权限和无答案策略。

## 8. 常见错误

- 只验证顺利案例。
- 把配置、密钥或本地路径写死。
- 没有记录版本、输入、输出与失败原因。

## 9. 排查方法

缩小为最小复现；核对输入类型和环境；读取最底层错误；检查日志中的请求 ID；再核对最新官方文档。
