# Python 工程基础

## 1. 这是什么

用于快速开发 API、数据处理、评测和 Agent 工作流的通用编程语言。

## 2. 为什么 Agent 开发需要它

它参与 Agent 的输入、状态、工具、数据、评测或部署链路，是把模型能力变成可维护产品的基础。

## 3. 设计师可以如何理解

像设计系统中的组件语言：语法是组件，模块是页面，包是产品。

## 4. 最小代码示例

```python
def normalize_brief(text: str) -> str:
    return ' '.join(text.strip().split())
```

## 5. 工作中的使用方式

编写服务、工具、数据流水线和自动化脚本。

## 6. 教学简化方案

先用一个输入、一个处理步骤、一个输出和一个错误案例跑通，不追求通用抽象。

## 7. 生产环境方案

使用类型提示、测试、日志、依赖管理和清晰包结构。

## 8. 常见错误

- 只验证顺利案例。
- 把配置、密钥或本地路径写死。
- 没有记录版本、输入、输出与失败原因。

## 9. 排查方法

缩小为最小复现；核对输入类型和环境；读取最底层错误；检查日志中的请求 ID；再核对最新官方文档。
