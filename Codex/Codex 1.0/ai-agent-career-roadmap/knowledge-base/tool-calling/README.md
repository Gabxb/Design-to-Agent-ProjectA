# Tool Calling

## 1. 这是什么

让模型选择经过定义的函数，并生成符合模式的调用参数。

## 2. 为什么 Agent 开发需要它

它参与 Agent 的输入、状态、工具、数据、评测或部署链路，是把模型能力变成可维护产品的基础。

## 3. 设计师可以如何理解

模型像服务设计中的调度员，工具才是真正执行动作的后台岗位。

## 4. 最小代码示例

```python
def get_policy(section: str) -> dict[str, str]:
    return {'section': section, 'content': '...'}
```

## 5. 工作中的使用方式

查询数据库、调用 API、计算、发送通知或创建工单。

## 6. 教学简化方案

先用一个输入、一个处理步骤、一个输出和一个错误案例跑通，不追求通用抽象。

## 7. 生产环境方案

参数校验、权限检查、超时、幂等、审计和人工审批。

## 8. 常见错误

- 只验证顺利案例。
- 把配置、密钥或本地路径写死。
- 没有记录版本、输入、输出与失败原因。

## 9. 排查方法

缩小为最小复现；核对输入类型和环境；读取最底层错误；检查日志中的请求 ID；再核对最新官方文档。
