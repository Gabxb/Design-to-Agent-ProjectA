# 大语言模型基础

## 1. 这是什么

根据上下文预测并生成文本或结构化内容的模型。

## 2. 为什么 Agent 开发需要它

它参与 Agent 的输入、状态、工具、数据、评测或部署链路，是把模型能力变成可维护产品的基础。

## 3. 设计师可以如何理解

像能力很强但没有项目背景、会受表达方式影响的协作者。

## 4. 最小代码示例

```python
messages = [{'role': 'system', 'content': 'Return concise JSON.'}, {'role': 'user', 'content': brief}]
```

## 5. 工作中的使用方式

提取、分类、生成、规划和自然语言交互。

## 6. 教学简化方案

先用一个输入、一个处理步骤、一个输出和一个错误案例跑通，不追求通用抽象。

## 7. 生产环境方案

记录模型版本、Token、延迟、成本、失败和评测结果。

## 8. 常见错误

- 只验证顺利案例。
- 把配置、密钥或本地路径写死。
- 没有记录版本、输入、输出与失败原因。

## 9. 排查方法

缩小为最小复现；核对输入类型和环境；读取最底层错误；检查日志中的请求 ID；再核对最新官方文档。
