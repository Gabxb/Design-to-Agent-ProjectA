# AI 应用安全

## 1. 这是什么

保护数据、工具权限和业务流程免受泄漏、注入与越权。

## 2. 为什么 Agent 开发需要它

它参与 Agent 的输入、状态、工具、数据、评测或部署链路，是把模型能力变成可维护产品的基础。

## 3. 设计师可以如何理解

像后台权限设计：界面上的提示不能替代真正的访问控制。

## 4. 最小代码示例

```python
if tool_name not in user.allowed_tools:
    raise PermissionError('tool not allowed')
```

## 5. 工作中的使用方式

认证、授权、输入过滤、审计和敏感信息处理。

## 6. 教学简化方案

先用一个输入、一个处理步骤、一个输出和一个错误案例跑通，不追求通用抽象。

## 7. 生产环境方案

最小权限、租户隔离、Secret 管理、威胁建模和红队测试。

## 8. 常见错误

- 只验证顺利案例。
- 把配置、密钥或本地路径写死。
- 没有记录版本、输入、输出与失败原因。

## 9. 排查方法

缩小为最小复现；核对输入类型和环境；读取最底层错误；检查日志中的请求 ID；再核对最新官方文档。
