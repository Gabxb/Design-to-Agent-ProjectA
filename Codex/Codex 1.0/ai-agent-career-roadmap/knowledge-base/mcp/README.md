# MCP

## 1. 这是什么

Model Context Protocol（模型上下文协议）为模型应用提供统一的工具与资源接入方式。

## 2. 为什么 Agent 开发需要它

它参与 Agent 的输入、状态、工具、数据、评测或部署链路，是把模型能力变成可维护产品的基础。

## 3. 设计师可以如何理解

像统一插件插口，让不同工具用一致方式被发现和调用。

## 4. 最小代码示例

```python
# 伪代码：客户端先列出工具，再以结构化参数调用
tools = client.list_tools()
result = client.call_tool('search_docs', {'query': query})
```

## 5. 工作中的使用方式

连接文件、数据库、设计工具和企业服务。

## 6. 教学简化方案

先用一个输入、一个处理步骤、一个输出和一个错误案例跑通，不追求通用抽象。

## 7. 生产环境方案

限制服务器信任边界、工具权限、参数和返回数据。

## 8. 常见错误

- 只验证顺利案例。
- 把配置、密钥或本地路径写死。
- 没有记录版本、输入、输出与失败原因。

## 9. 排查方法

缩小为最小复现；核对输入类型和环境；读取最底层错误；检查日志中的请求 ID；再核对最新官方文档。
