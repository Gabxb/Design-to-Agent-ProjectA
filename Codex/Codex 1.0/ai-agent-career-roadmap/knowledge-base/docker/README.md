# Docker

## 1. 这是什么

把应用及运行依赖封装为可重复启动的容器。

## 2. 为什么 Agent 开发需要它

它参与 Agent 的输入、状态、工具、数据、评测或部署链路，是把模型能力变成可维护产品的基础。

## 3. 设计师可以如何理解

像把字体、组件和素材连同设计稿一起打包，减少环境差异。

## 4. 最小代码示例

```python
FROM python:3.12-slim
WORKDIR /app
COPY . .
CMD ["python", "-m", "src.main"]
```

## 5. 工作中的使用方式

统一本地、测试和部署环境。

## 6. 教学简化方案

先用一个输入、一个处理步骤、一个输出和一个错误案例跑通，不追求通用抽象。

## 7. 生产环境方案

使用非 root 用户、健康检查、多阶段构建和最小镜像。

## 8. 常见错误

- 只验证顺利案例。
- 把配置、密钥或本地路径写死。
- 没有记录版本、输入、输出与失败原因。

## 9. 排查方法

缩小为最小复现；核对输入类型和环境；读取最底层错误；检查日志中的请求 ID；再核对最新官方文档。
