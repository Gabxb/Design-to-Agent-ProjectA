## 10. 工程要求

- Python 代码使用类型提示；配置不写死本地路径。
- API Key 只从环境变量读取；日志不记录完整密钥或敏感资料。
- 写清运行命令、输入输出、失败表现和验收方法。

- [ ] 交付物可以按 README 运行。
