# 方案 C：设计师优势版：课程结构

该课程不将设计背景视为需要绕开的短板，而是将其转化为需求澄清、信息架构、质量评测和人机协同设计能力。每个阶段都要求提交代码、文档、验收记录和复盘。

| 周次 | 阶段 | 关键能力 |
|---|---|---|
| 1–4 | 设计需求到 API | 设计语言结构化、Python、FastAPI、数据库 |
| 5–8 | 研究体验 AI | UX Research Copilot、提示词、Schema、工具 |
| 9–12 | 规范知识体验 | RAG、引用、权限、知识架构 |
| 13–16 | 智能设计评审 | LangGraph、Human-in-the-loop、MCP |
| 17–20 | 生产化产品 | 评测、安全、部署、运营 |
| 21–24 | 求职冲刺扩展 | 作品集叙事、Demo、面试、模拟工作 |

## 统一工程质量线

所有阶段遵守：Python 类型提示；环境变量保存密钥；输入验证；结构化日志；关键功能测试；README 可复现；Docker 化；不使用虚构真实用户数据。框架或模型 API 可能变化，实施前必须核对官方文档。
