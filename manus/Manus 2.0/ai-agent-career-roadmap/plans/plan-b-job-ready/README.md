# 方案 B：求职冲刺版



| 维度 | 说明 |
|---|---|
| 适合人群 | 可集中投入并希望快速获得可展示项目的学习者 |
| 学习周期 | 16 周 |
| 每周投入 | 每周 20–25 小时 |
| 学习节奏 | 每 4 周交付一个 Demo；工程基础按项目需求即时补齐。 |
| 技术深度 | 项目深度与展示优先，覆盖关键工程底座。 |
| 项目数量 | 4 个展示项目 |
| 就业方向 | AI 应用/Agent 开发岗位、快速原型岗位 |
| 优势 | 作品集、部署、README 和面试叙事形成快。 |
| 风险 | 高强度，基础薄弱时容易形成理解债务。 |
| 选择建议 | 只有在每周可投入 20 小时以上且能规律复盘时选择。 |

## 使用方式

本方案的高层安排位于 `CURRICULUM.md` 和 `WEEKLY_SCHEDULE.md`。默认执行目录是根目录的 `weeks/`，它按方案 C 创建了 24 周可执行任务；切换方案时请使用 `update_plan.py` 保留历史进度。
