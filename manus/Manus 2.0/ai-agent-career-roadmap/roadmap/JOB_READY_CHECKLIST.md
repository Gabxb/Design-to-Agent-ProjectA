# 求职就绪检查清单

## 工程证据

- [ ] 至少 3 个可运行项目，至少 1 个非设计领域综合项目。
- [ ] 每个项目都有 README、需求、架构、测试、安全、评测和部署说明。
- [ ] 每个项目展示失败处理、人工确认或安全边界。
- [ ] GitHub 提交历史可读，密钥和真实敏感数据未被提交。

## 作品集表达

- [ ] 每个项目能在 3 分钟说明问题、用户、架构、取舍和结果。
- [ ] 每个项目有 5 分钟可运行 Demo 脚本。
- [ ] 架构图中的模型、工具、数据、人工确认和日志边界清晰。

## 面试准备

- [ ] 能解释 Python 类型、异常、测试、HTTP、SQL 和 Docker。
- [ ] 能解释 RAG 的切分、检索、引用、评测与数据隔离。
- [ ] 能解释 Agent 与 Workflow 的边界、状态、终止、工具权限和 HITL。
- [ ] 能给出一次失败案例、修复方式和以后预防方案。

## 投递前

- [ ] 简历与目标岗位描述一致。
- [ ] GitHub 主页置顶项目和联系方式准确。
- [ ] 投递记录包含岗位、日期、项目版本和后续动作。
