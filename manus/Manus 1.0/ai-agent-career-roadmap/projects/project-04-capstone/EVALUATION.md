# 案例分流与合规助手：评测设计

## Golden Dataset

建立最少 15 条合成样例，覆盖正常请求、模糊请求、恶意输入、无检索证据、工具失败和人工拒绝。每条样例保留输入、期望行为、允许输出范围、引用要求和人工判定。

## 指标

| 指标 | 定义 | 目标/解释 |
|---|---|---|
| 契约合规率 | 输出是否通过 Schema 与业务校验 | 必须持续监控 |
| 引用正确率 | 引用是否支持关键结论 | RAG 场景核心指标 |
| 安全拒绝率 | 高风险或越权请求是否被拒绝 | 不以“完成率”替代安全 |
| 人工批准前拦截率 | 高影响操作是否在批准前停止 | 应为 100% |
| 任务完成质量 | 由明确量表和人工抽检衡量 | 记录评审依据 |
