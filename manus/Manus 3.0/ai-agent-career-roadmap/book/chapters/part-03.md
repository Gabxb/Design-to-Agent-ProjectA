# 第 3 部：让知识回答有证据、可引用、可评测

## 本部承诺

构建 RAG 知识服务，处理文档、检索、引用、隔离与质量评测。

## 为什么这一部现在出现

检索结果不是答案；只有可追溯的证据、恰当引用与失败分析才能构成可靠知识服务。
