# 第 2 部：让模型输出可靠且工具调用受控

## 本部承诺

学习将 LLM 的灵活能力装入明确的任务、Schema、工具和安全边界。

## 为什么这一部现在出现

模型负责提出建议；应用代码负责验证、授权、执行和记录。

## 本部章节

| 章节 | 本周主题 | 本周可验证产出 |
|---|---|---|
| [第 05 章](chapter-05.md) | LLM、Token 与提示词结构 | 可版本化的提示词实验记录 |
| [第 06 章](chapter-06.md) | 结构化输出与 JSON Schema | 研究访谈洞察结构化 API |
| [第 07 章](chapter-07.md) | Tool Calling、重试与安全边界 | 受控工具调用循环 |
| [第 08 章](chapter-08.md) | UX Research Copilot 集成冲刺 | 可演示的研究资料整理助手 |

## 本部项目

本部的主要成果将沉淀到 **[UX Research Copilot](../../projects/project-01-tool-calling/README.md)**。不要等到本部最后一周才打开项目目录；从第一章起就把每周产出连接到项目任务板、README 和测试中。

## 建议阅读与实践节奏

1. 先通读本部四章标题，理解能力的递进关系。
2. 每周先读章节，再读 `weeks/week-XX/WEEK_PLAN.md`。
3. 每天完成 `days/day-XX.md` 的最小闭环，并在 `progress/DAILY_LOG.md` 中写下事实。
4. Day 7 回到本部，检查你是否正向项目里程碑推进。
