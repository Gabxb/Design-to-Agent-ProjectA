# 方案 C：设计师优势版：路线图

## 计划定位

将用户研究、信息架构、交互设计和 Human-in-the-loop 转化为工程优势。

| 属性 | 设置 |
|---|---|
| 学习周期与投入 | 20 周核心 + 4 周求职冲刺，每周 15–20 小时 |
| 主要方向 | AI Agent 开发工程、AI 产品工程、设计技术/智能体验方向 |
| 默认切换原则 | 保留已完成任务和个人笔记，仅调整后续未完成任务。 |

## 阶段路径

| 阶段 | 名称 | 核心技术 | 阶段项目 |
|---:|---|---|---|
| 1 | 基础 | Python、API、数据库、测试、Docker | 设计需求结构化助手 API |
| 2 | LLM | Prompt、Structured Output、Tool Calling | UX Research Copilot |
| 3 | RAG | 解析、检索、引用、评测、权限隔离 | 设计规范知识库 Agent |
| 4 | 工作流 | 状态、HITL、LangGraph、MCP | 智能设计评审 Agent |
| 5 | 生产化 | Evaluation、安全、Tracing、部署 | 案例分流与合规助手 |
| 6 | 求职 | GitHub、Demo、简历、面试、投递 | 全作品集 |

## 使用方式

查看 `WEEK_INDEX.md` 确认该方案的节奏；查看 `PROJECT_PATH.md` 了解项目如何递进；查看 `RISKS.md` 提前处理时间、基础、范围与工程质量风险。
